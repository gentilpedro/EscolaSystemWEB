
# 📚 Sistema Escolar - SaaS Multi-Tenant

Um sistema completo de gerenciamento escolar desenvolvido em React + Vite com Tailwind CSS, pronto para integração com sua API.

## 🚀 Features

### 👨‍💼 Administração

- Dashboard com dados gerais de usuários e escolas
- Gerenciamento de escolas
- Gerenciamento de usuários
- Configurações do sistema

### 🏫 Direção

- Dashboard com estatísticas da escola
- Gerenciamento de funcionários
- Gerenciamento de turmas
- Gerenciamento de alunos
- Visualização de relatórios
- Gerenciamento de chamados disciplinares

### 👨‍🏫 Professores

- Dashboard com resumo das turmas
- Página de chamada com registro automático de presença
- Lançamento de notas
- Visualização de turmas e desempenho
- Criação e gerenciamento de chamados disciplinares

### 👨‍👩‍👧‍👦 Pais

- Dashboard com histórico de chamados
- Visualização de chamados disciplinares
- Notificações de eventos

### 🎓 Alunos

- Dashboard com notas e faltas
- Visualização de notas por matéria
- Histórico de faltas
- Visualização de trabalhos pendentes
